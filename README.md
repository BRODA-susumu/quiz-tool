# 配信クイズツール（回答者・管理者・表示用）

配信でクイズ番組を作るための3画面連動ツールです。回答者がスマホ等で回答を入力し、管理者が確認して選び、OBSのブラウザソースに大きく表示します。ルームコードで部屋を分けるので、複数の番組が同時に使えます（一般公開OK）。

## ファイル

- `answer.html` … 回答者用（スマホ・PCのブラウザで回答を入力）
- `admin.html` … 管理者用（回答をリアルタイム確認・表示操作）
- `display.html` … 表示用（OBSのブラウザソースに入れる／1920×1080）

3ファイルはどこに置いてもOKです（同じフォルダに一緒に置いてください）。ローカルでダブルクリックして開くだけでも動きますが、回答者が別端末から使う場合はネットにアップロード（GitHub Pages・Netlify・レンタルサーバー等）してURLを共有してください。同期は Supabase（クラウドDB）を経由するので、別ネットワークからでもリアルタイムに連動します。

## 使い方

1. **管理者**：`admin.html` を開き、好きな「ルームコード（合言葉）」を入力して「入室」。
   - 画面に「回答者用URL」「OBS表示用URL」が出るので、コピーして使います。
2. **表示用**：OBSで「ブラウザ」ソースを追加し、URLに **OBS表示用URL** を貼り付け。幅1920・高さ1080に設定。
3. **回答者**：**回答者用URL** を各自のスマホ等で開き、名前を入れて「参加」。回答を入力すると自動で送信されます。1行が9文字を超えると自動で折り返され（手動改行は尊重）、表示用にも同じ折り返しで出ます。
4. **管理者**の操作：
   - 各回答者の行に「表示」「正解」の2つのチェックボックス。
   - 見せたい人に「表示」チェック → **「📺 OBSに表示」** ボタンで表示用に反映（ボタンを押すまで表示は変わりません）。
   - 複数人チェックすれば自動でいい感じにレイアウトされます（1〜8人以上対応）。
   - 「正解」にチェックを入れると、その回答者の背景がレッドに変わります（デフォルトはブルー）。
   - **「リセット」** … 全員の回答・チェック・表示を消します（名前とポイントは残ります）。
   - 名前の手前の欄に**現在の獲得ポイント**をメモできます。**「🏅 ポイントを一括反映」** で、表示用にポイントを反映（各回答枠に「〇pt 名前」の形で表示）。

## ポイント表示について

「ポイントも表示」にチェックを入れて「OBSに表示」または「ポイントを一括反映」を押すと、各回答枠の名前の手前に黄色の「〇pt」バッジが出ます。得点発表の演出に使えます。

## 技術メモ

- 同期は Supabase（Project: `quiz-tool`）を使用。テーブルは `quiz_players`（回答者・回答・ポイント）と `quiz_display`（表示スナップショット）。
- ルームコードで論理的に部屋を分けています。合言葉が被ると同じ部屋になるので、公開時は推測されにくいコードを推奨。
- Realtime が切れても15〜20秒ごとのポーリングで復帰します。
- APIキーは公開用（publishable / anon）で、フロントに埋め込む前提のものです。

## 注意

- 一般公開する場合、ルームコードを知っている人は誰でもその部屋に参加・閲覧できます。番組ごとにコードを変えてください。
- 古い部屋のデータは自動削除されません。気になる場合は管理者の「✕」で回答者を削除できます。
