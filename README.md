# 配信クイズツール

配信でクイズ番組を作るための3画面連動ツールです。回答者がスマホ等で回答し、管理者が確認・操作して、OBSのブラウザソースに大きく表示します。ルームコードで部屋を分けるので、複数の番組が同時に使えます（一般公開OK）。同期は Supabase（クラウドDB）経由なので、別ネットワークからでもリアルタイムに連動します。

**2種類のクイズがあります。** `index.html` を開くとどちらの管理者用も選べます。

## ファイル

### 記述式（回答者が自由に文字入力）
- `answer.html` … 回答者用
- `admin.html` … 管理者用
- `display.html` … OBS表示用（1920×1080）

### 選択式（2〜9択・タップで回答）
- `select-answer.html` … 回答者用
- `select-admin.html` … 管理者用
- `select-display.html` … OBS表示用（1920×1080）

### 共通
- `index.html` … 入口（両方の管理者用へのリンク）

ファイルはどこに置いてもOK（同じフォルダにまとめて置いてください）。回答者が別端末から使う場合はネットにアップロード（GitHub Pages 等）してURLを共有します。

## 使い方

1. **管理者**：`admin.html` を開き、好きな「ルームコード（合言葉）」を入力して「入室」。
   - 画面に「回答者用URL」「OBS表示用URL」が出るので、コピーして使います。
2. **表示用**：OBSで「ブラウザ」ソースを追加し、URLに **OBS表示用URL** を貼り付け。幅1920・高さ1080に設定。
3. **回答者**：**回答者用URL** を各自のスマホ等で開き、名前を入れて「参加」。回答を入力すると自動で送信されます。1行が9文字を超えると自動で折り返され（手動改行は尊重）、表示用にも同じ折り返しで出ます。
4. **管理者**の操作：
   - 各回答者の行に「表示」「正解」の2つのチェックボックス。
   - 見せたい人に「表示」チェック → **「📺 OBSに回答を表示」** ボタンで表示用に反映（ボタンを押すまで表示は変わりません）。**「☑ 全員を表示にチェック」** で一括チェックできます。
   - 複数人チェックすれば自動でいい感じにレイアウトされます（1〜8人以上対応）。
   - 「正解」にチェックを入れると、その回答者の背景がレッドに変わります（デフォルトはブルー）。
   - **「リセット」** … 全員の回答・チェック・回答表示を消します（名前・ポイント・問題文は残ります）。
   - 名前の手前の欄に**現在の獲得ポイント**をメモでき、**＋／−ボタン**で増減できます。

### ポイント関連
- **「🏅 回答欄にポイントを表示」** … 表示にチェックした人の回答枠に、回答の代わりに「3pt」など現在ポイントを大きく表示します（得点発表の演出）。
- **「名前の横にptを表示」** … 回答表示中、各カードの名前の手前に黄色の「〇pt」バッジを出します。
- **「正解で自動+1」モード** … ONにすると「正解」チェックを入れた瞬間にその人のポイントが自動で+1されます（チェックを外しても減りません。修正は＋／−ボタンで）。

### 問題表示
- 「問題表示」枠に問題文を入力して各ボタンで操作します。
  - **表示** … 回答者用の上部とOBSに問題文を反映。OBSは、回答を表示していないときは中央に大きく、回答を表示しているときは上部の白帯に出ます。
  - **保存** … 問題文をこの端末（ブラウザ）に保存。プルダウンからいつでも呼び出せます（事前の問題作成用）。
  - **選択を削除** … プルダウンで選んだ保存済み問題を削除（誤字などの修正用）。
  - **入力クリア** … 入力中の問題文を消します（OBSの表示は消えません／消すときは「問題を消す」）。
  - **問題を消す** … OBS・回答者の問題文表示を消します。
- 保存した問題リストは管理者のそのブラウザだけに残ります（同じPCならいつでも使えます）。

### 表示設定・結果発表（記述式・選択式 共通）
- **OBSフォント** … OBS表示のフォントを6種（ゴシック／丸ゴシック／明朝／ポップ体／極太インパクト／手書き風）から選べます。
- **ポイント表示** … 黄色のプレートに黒文字で表示。トップ（同率含む）のポイントは赤文字になります。
- **🏆 最終結果発表** … ポイント順のランキング（順位＋名前＋pt）をOBSに表示。1ページ10名で、「次の10名 ▶／◀ 前の10名」でページを送れます。「結果表示を終了」で通常表示に戻ります。

## 選択式の使い方

1. `select-admin.html`（または index.html →「選択式」）を開き、ルームコードで入室。
2. 「問題作成」で問題文と選択肢（2〜9択）を入力し、**正解の選択肢に「正解」チェック**を入れます。「選択肢を追加」で最大9択まで増やせます。
3. **「📢 この問題を出題」** で回答者とOBSに問題＋選択肢が出ます。
4. 回答者は選択肢をタップして回答（**選び直しはできません**）。管理画面と「選択人数を表示」で各選択肢の人数がリアルタイムに分かります。
5. OBS表示は **「問題+選択肢」** と **「個人カード（誰が何を選んだか）」** を切り替えられます。
6. **「✅ 正解発表」** で正解の選択肢がハイライトされ、**正解者に自動で+1**されます（同じ問題では二重加算しません）。
7. 問題は「💾 保存」で問題文・選択肢・正解ごとこの端末に保存でき、プルダウンからいつでも呼び出せます。「選択を削除」で保存済みを削除。
8. 「リセット（回答クリア）」で全員の回答と出題表示を消します（名前・ポイントは残ります）。

## 技術メモ

- 同期は Supabase を使用。記述式は `quiz_players`／`quiz_display`、選択式は `quiz_select_players`／`quiz_select_display`。記述式と選択式は別テーブルなので、同じルームコードでも互いに干渉しません。
- ルームコードで論理的に部屋を分けています。合言葉が被ると同じ部屋になるので、公開時は推測されにくいコードを推奨。
- Realtime が切れても15〜20秒ごとのポーリングで復帰します。
- APIキーは公開用（publishable / anon）で、フロントに埋め込む前提のものです。

## 注意

- 一般公開する場合、ルームコードを知っている人は誰でもその部屋に参加・閲覧できます。番組ごとにコードを変えてください。
- 古い部屋のデータは自動削除されません。気になる場合は管理者の「✕」で回答者を削除できます。
